## Getting started

| What you'd like to do   | Where to start                                                                                                |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| Explore public work     | [Browse my public repositories](https://github.com/Nsmart0?tab=repositories).                                 |
| Use a project           | Open its README and follow its download and setup instructions.                                               |
| Open a private project  | Sign in to the GitHub account with access, then open the repository link shared with you.                     |
| Find the right download | Use the package linked in the project's instructions. GitHub's **Code → Download ZIP** provides source files. |
